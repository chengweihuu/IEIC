## 3. 常用调用方式

### 3.1 SSH登录

作用：从接入机器人网络的终端登录对应主机，之后输入的命令在该主机执行。SSH登录本身不驱动机器人；使用`exit`退出。密码在SSH提示时输入，下面的注释不作为命令执行。

```bash
# 导航及业务主机
ssh robot@192.168.1.120
# 密码请从本地设备凭据记录获取，不提交到仓库。
# 云台及视频主机
ssh root@192.168.1.214
# 密码请从本地设备凭据记录获取，不提交到仓库。
```

### 3.2 视频读取与截图

作用：连接相机的RTSP视频流，解码并保存一帧图片，用于检查画面是否正常。第一条保存可见光图片，第二条保存红外伪彩图片；每条执行完一帧即退出，不会驱动云台。

可见光：`rtsp://192.168.1.214:8554/visible`  
红外：`rtsp://192.168.1.214:8556/ir`

在接入机器人网络且已安装`ffmpeg`的终端执行；图片保存到该终端运行命令时所在的目录，不是自动保存到机器人上：

```bash
ffmpeg -hide_banner -loglevel warning -rtsp_transport tcp \
  -i rtsp://192.168.1.214:8554/visible -frames:v 1 -update 1 -y visible.jpg

ffmpeg -hide_banner -loglevel warning -rtsp_transport tcp \
  -i rtsp://192.168.1.214:8556/ir -frames:v 1 -update 1 -y thermal.jpg
```

输出：`visible.jpg`为可见光截图，`thermal.jpg`为红外伪彩截图。红外截图中的颜色不等于逐像素温度数据；温度统计使用3.6的脚本读取，完整温度矩阵使用3.9的脚本。

| 参数 | 作用 |
|---|---|
| `-hide_banner` | 隐藏FFmpeg版本和编译信息 |
| `-loglevel warning` | 只显示警告和错误 |
| `-rtsp_transport tcp` | 使用TCP传输RTSP媒体数据 |
| `-i 地址` | 指定输入视频流 |
| `-frames:v 1` | 只输出一帧视频图像，随后退出 |
| `-update 1` | 按单个图片文件输出，不使用连续图片编号；配合一帧限制只写一次 |
| `-y` | 直接覆盖已有同名文件 |
| 行末 `\` | Bash续行符，把多行作为同一条命令执行 |

### 3.3 扬声器播放

作用：通过导航主机的USB音频设备播放一个已有WAV文件，验证扬声器是否实际发声。它会发出声音，但不测试文本转语音、麦克风或双向对讲；不生成结果文件。

登录导航主机后执行：

```bash
aplay -D plughw:0,0 /usr/share/sounds/alsa/Front_Center.wav
```

`-D plughw:0,0`指定声卡0、设备0；后面的路径为待播放的WAV文件。重启或重新插接后，可用`aplay -l`列出声卡并核对编号。

### 3.4 雷达与IMU读取

作用：只读检查ROS传感器数据，不驱动机器人，不自动保存数据文件。

登录导航主机后执行：

```bash
source /opt/ros/noetic/setup.bash
rostopic hz /lidar_points
# Ctrl+C结束频率观察后，再执行下一条
rostopic echo -n 1 /imu/data
```

- `source /opt/ros/noetic/setup.bash`：为当前终端加载ROS环境，不会启动传感器驱动。
- `rostopic hz /lidar_points`：持续统计点云消息频率，正常参考值约10 Hz；按Ctrl+C结束。
- `rostopic echo -n 1 /imu/data`：打印一条IMU消息后退出，用于检查消息内容；仅一条消息不能验证100 Hz频率。

### 3.5 气体持续监测与记录

作用：通过SSH持续读取厂家采集日志，把CO、氧气、温湿度回复显示出来并记录文件，用于观察变化趋势。该脚本不直接向气体探头发送采样或控制命令。

在项目根目录执行，按提示输入导航主机SSH密码：

```bash
python3 测试结果/2026-10-12_接口复核/monitor_gas.py
```
